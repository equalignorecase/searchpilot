# IBM Plex Sans Thai

Source: https://github.com/google/fonts/tree/main/ofl/ibmplexsansthai

Weights: Regular 400, Medium 500, SemiBold 600, Bold 700.
The original TTF files were compressed to WOFF using FontTools without subsetting or changing names/glyphs. SIL Open Font License is included in OFL.txt. Next.js serves these files locally through next/font/local.
